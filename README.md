🎯 Core Features Overview
1. Landing Page + Auth
Sign Up / Sign In with basic details (email, username, password, etc.)

Optionally: Google OAuth (if you want fast logins)

Session-based or token-based auth (JWT recommended)

2. Home Page with Two Modes
✨ Mode 1: Practice with ML-Generated Challenges
User selects difficulty (Easy, Medium, Hard)

ML model suggests problems accordingly (fine-tune or use existing GPT/LLM APIs)

Code editor with:

Language selection

Run + Submit buttons

Test cases visibility (or hidden test cases for final submission)

Evaluation:

Code is sent to backend, run securely (e.g., via Docker or Judge0)

Returns a scorecard with:

Passed test cases

Time/space complexity

Final verdict (Accepted, Wrong Answer, etc.)

ML-Based Code Review:

After code runs, a lightweight model gives suggestions:

Better logic / syntax tips

Identifies unused vars, inefficient loops, etc.

🧪 Mode 2: Contests & Admin-Hosted Competitions
Admin Panel:

Create/edit contests

Add custom problems

Schedule timing

Enable multiple contests at once

Users:

Join ongoing contests

Submit solutions during live timer

Real-time Leaderboard:

Score updates based on fastest + correct submissions

Admin sees all submissions in real time

Security Add-ons:

Webcam-based cheating detection using OpenCV

Code plagiarism detection (see suggestions below)
